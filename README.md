# IT Dashboard

A responsive dashboard for viewing IT operations using sample data.

## Features

- System health and uptime overview
- Network traffic chart
- Device inventory
- Searchable support tickets
- Infrastructure alerts
- Responsive desktop and mobile layout

## Requirements

- Node.js 20 or newer
- npm

## Run locally

1. Clone the repository:
   git clone https://github.com/jimbryansantos-blip/Dashboard_test.git

2. Enter the project folder:
   cd Dashboard_test

3. Start the server:
   npm run dev

4. Open http://localhost:3000 in your browser.

No additional dependencies need to be installed.

## Check JavaScript syntax

npm run build

This command checks syntax; no compilation is required.

## Technology

HTML, CSS, JavaScript, and a Node.js HTTP server.

## Demo limitations

All data is simulated. The dashboard does not connect to live IT
systems, and changes reset when the page reloads.
